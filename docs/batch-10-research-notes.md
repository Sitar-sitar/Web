# 第10バッチ 個別ガイド調査記録

調査日：2026-08-26（JST）  
対象：HSR（ジェイド、ジェパード、セイバー、セイレンス）、原神（エウルア、エスコフィエ、エミリエ）、ZZZ（イドリー、ヴェリナ、オルペウス&「鬼火」）

## 運用上の確認事項

- 各キャラクターは**ゲーム別の実ソースIDを第一キー**として扱い、表示名が同じ・類似する別実装へ推測適用しない。
- 公開UIDとの比較値には、戦闘中、編成依存、武器依存、条件付き凸効果を加算しない。必要な効果は注記として分離し、`activeTargetChanges` とパーティの `targetChanges` は根拠が明確な常時・公開値側の補正に限る。
- 公開プロフィールの取得は、画面上の **Search** の明示実行時だけ検証する。保存済みUIDの復元、画面読み込み、ゲーム切替、再読み込みで取得を開始しない。
- 公式実装が未確認、またはソースIDが未解決の凸は、安全に `preparing` として扱い、効果を創作しない。
