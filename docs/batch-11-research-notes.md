# 第11バッチ（20名）個別ビルド・凸・推奨PTの調査記録

調査開始日：2026-08-27（JST）  
対象：HSR（セーバル、ゼーレ、ダリア、トリビー、ナターシャ、ヒアンシー、ファイノン、フォフォ）、原神（オロルン、カーヴェ、ガイア、カチーナ、キィニチ、キャンディス）、ZZZ（カリン、クレタ、シーシィア、シグリッド、スターライト･ビリー、ダイアリン）

## 運用変更と安全基準

- ユーザー指示により、今回から分割公開の対象を **20キャラクター単位** とする。第10バッチ公開時点の監査済み100件から、今回の第11バッチ完了時は120/248を目標とする。
- 各キャラクターはゲーム別の実ソースIDを第一キーとして扱う。名前が同じ・類似する別実装を推測で統合せず、スナップショットでIDが確認できない場合は凸データを `preparing` に留める。
- 公開UIDとの比較値へ、戦闘中、編成依存、武器依存、条件付きの凸効果を加算しない。これらは説明注記に分離し、`activeTargetChanges` とパーティの `targetChanges` は空を維持する。
- 公開UID照会は画面上の **Search** の明示操作だけで行う。保存UIDの復元、ページ読み込み、ゲーム切替、再読み込みでは取得を開始しない。
- 実装の直前に、個別の更新日、目標、装備、全6段階効果、実名入りパーティを各ソース本文から再照合する。
