# 第3バッチ：個別ビルド・凸・推奨PTの研究記録

第3バッチは、サンデー、ブートヒル、黄泉、霊砂、雷電将軍、ナヒーダ、鍾離、ビビアン、ジェーン、エレンを対象とする。各項目では、公開プロフィールで比較する戦闘外数値と、戦闘中・凸・編成条件でのみ得られる効果を分離する。

## サンデー（HSR）

Game8の個別ガイドは2026-06-19更新で、胴体は会心ダメージ、脚部は速度、オーブはHP%または防御力%、縄はEP回復を推奨する。戦闘外の目標は会心ダメージ200%以上、速度は主力アタッカーより1低い134付近または160であり、効果抵抗30%以上は折れた竜骨の条件として扱う。[1]

推奨PTはアグライア・ロビン・フォフォの召喚編成、単体ハイパーキャリー、姫子・ジェイドの2アタッカー構成を例示する。召喚物を含む行動順操作、必殺技のEP回復、会心バフは戦闘中の効果であり、公開プロフィールの現在値へ加算しない。[1] Prydwenは2026-05-31更新で、-1速度型は134または主力より1低い速度、ハイパー速度型は160以上、会心ダメージ180〜220%以上を示す。[2]

全6星魂については、PrydwenのE1（防御無視）、E2（初回必殺技時のSP回復と与ダメージ）、E3/E5（スキルレベル）、E4（行動時EP）、E6（会心率バフのスタック化・超過会心率の会心ダメージ変換）を照合した。いずれも公開プロフィールの現在値へ直接加算しない。戦闘内の会心率バフは、公開プロフィールの目標値を下げる数値補正としても未検証のため、この段階では登録しない。[2]

## ブートヒル（HSR）

Game8の2026-06-19更新ガイドは、鉄騎4セット／タリア2セット、速度靴、物理属性ダメージオーブ、撃破特効縄を推奨する。公開プロフィールでは撃破特効200%以上、速度135・145・160の各閾値、会心率40〜55%以上（戦闘外）、会心ダメージ50%以上（戦闘外）を示す。タリアの効果には速度145が必要である。[3]

PTは、ブートヒル・サンデー・ルアン・メェイ・霊砂の撃破編成、開拓者（調和）・アスター・ナターシャのF2P編成、帰忘の流離人・ダリア・霊砂の超撃破編成を例示する。サンデーの追加行動、ルアン・メェイの撃破支援、調和開拓者の超撃破は戦闘中条件であり、公開プロフィール現在値には加算しない。[3]

Prydwenの2026-05-31更新ガイドでE1〜E6を確認した。E1の防御無視、E2の撃破特効+30%、E4の被ダメージ・被与ダメージ変化、E6の追加撃破ダメージはいずれも戦闘中の条件付き効果であり、公開プロフィールの目標補正としては登録しない。[4]

## 黄泉（HSR）

Game8の2026-06-19更新ガイドは、死水4セット／出雲2セット、会心胴、速度または攻撃力%靴、雷属性ダメージまたは攻撃力%オーブ、攻撃力%縄を推奨する。公開プロフィールの目標は会心率70%以上、会心ダメージ160%以上、攻撃力3,000〜3,500、速度101または135以上である。[5]

E0/E1では虚無2名による追加能力の倍率を満たすPT、E2では虚無1名と調和1名の編成を分けて扱う。Game8はモルトナックス・ブレード、サフェル、ヴェルトを含む虚無軸と、E2で花火を加える軸を例示する。デバフ、被ダメージ上昇、追加行動、星魂由来の会心は戦闘中・編成依存であり、公開プロフィール現在値には加算しない。[5]

Prydwenの2026-05-31更新ガイドでE1〜E6を確認した。E1のデバフ対象への会心率+18%は戦闘中条件のため、公開値の目標補正には未登録とする。E2の虚無人数条件緩和、E4の必殺技被ダメージ上昇、E6の耐性貫通も公開値の現在・目標へ直接加算しない。[6]

## 霊砂（HSR）

Game8の2026-06-19更新ガイドでは、一般に鉄騎2セット／メッセンジャー2セット、超撃破時は鉄騎4セット、治癒量胴・速度靴・攻撃力%オーブ・EP回復または撃破特効縄を提示する。撃破特効は戦闘中200%、鉄騎4セットでは250%、速度は134・143・160以上、タリアでは145を目安とする。[7]

より新しいGameWithの2026-07-31更新ガイドは、撃破編成の公開値として撃破特効140%、速度160、攻撃力2,700を例示し、戦闘中250%には光円錐・味方セット・編成バフが含まれるため、公開プロフィールへ混入させない方針を明記している。PTはホタル・帰忘の流離人・ダリア、マダム・ヘルタ・アナイクス・トリビー、三月なのか（巡狩）・調和開拓者・ルアン・メェイを確認した。[8]

E1の弱点撃破効率・防御低下、E2の味方撃破特効+40%、E4の回復、E6の全属性耐性低下・追加攻撃はすべて戦闘内効果であり、公開プロフィールの現在値・目標値へ自動加算しない。[8]
