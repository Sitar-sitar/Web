# キャラクター識別基盤

## 目的

公開プロフィールの表示名は、取得元のローカライズ遅延、派生実装、別バージョン、未公開メタデータにより不完全になり得る。このため、**表示名を主キーにせず、`ゲームID:取得元キャラクターID` を不変の識別子**として扱う。

| フィールド | 用途 |
| --- | --- |
| `key` | `hsr:1506` のようなゲーム横断で一意な内部識別子 |
| `displayName` | UI・ガイド・推奨編成で使う名称 |
| `variantOf` | 基礎キャラクターと別実装であることを明示する補助情報 |
| `resolved` | 取得元または確認済みIDマッピングで名称を解決できたか |
| `resolution` | `provider`、`curated-id-map`、`unresolved` の解決経路 |

## 解決の優先順位

1. 取得元が返す有効な名称を使用する。
2. 取得元の名称が空、数値のみ、プレースホルダーの場合のみ、確認済みIDマッピングを参照する。
3. 解決できない場合は `未解決のキャラクター（ID ...）` と表示する。**既存キャラクター名への推測置換はしない。**

この方針により、別IDの「銀狼Lv.999」を基礎実装の「銀狼」と統合せず、属性・運命・個別ガイド・推奨PTも銀狼から継承しない。

派生実装は、表示名が基礎キャラクターと一致する場合でも、`variantOf` が設定されていれば基礎キャラクター専用の個別ガイドを使用しない。代わりに、そのIDの運命・特性から生成する汎用ガイドを使い、データが不足する場合は未解決として表示する。

## 運用上の注意

新IDを追加する際は、まず取得元カタログの名称を優先する。補助マッピングは、一次情報または取得元の安定データで確認できた場合だけ追加する。未解決IDを既存の名前ベース・ガイド・編成へ接続してはいけない。

## 回帰検証

`server/characterIdentity.test.ts` は、HSR `1506` の派生分離、原神 `10000125` の名称解決、未知IDの非推測表示を検証する。各ゲームの正規化経路は必ず `CharacterProfile.identity` を返し、ホーム画面はIDと派生実装を表示する。

2026-08-25 JSTには、ユーザー提示のHSR UID `806071233` で実画面照会を再試行した。主取得の待機時間を6秒へ制限してEnkaフォールバックの実行時間を確保したところ、ID `1506` は **銀狼Lv.999／虚数／歓楽** として表示され、`SOURCE ID / hsr:1506` および「銀狼とは別実装」のラベルを確認できた。個別ビルド・推奨PTも基礎キャラクターの銀狼ではなく、銀狼Lv.999として生成されることを確認した。

### 2026-08-25 JST 全件カタログ監査

公開静的カタログをID、名称、画像参照の3点で走査し、HSR 95件、原神 128件、ZZZ 58件、**合計281件**の有効実装を回帰スナップショットへ保存した。全281件で `game:sourceId` の一意キー、有効な非数値名称、画像参照文字列を確認した。HSRの開拓者10件は取得元が共通の `{NICKNAME}` を返すため、上表のID別ラベルを適用する。

原神の公開カタログには、名称・画像とも空の6レコード（`10000117`、`10000118`、`10000998`、`10000999`、`11000998`、`11000999`）が含まれた。これらはカタログ上でもメタデータが空であるため、プレイアブル実装として推測解決せず、全件検証の対象外として明示した。実プロフィールで同様の未知IDが返った場合は、既存名へ統合せず「未解決のキャラクター」として安全に表示する。

| 検証対象 | 公開UID | 実画面で確認した事項 |
| --- | --- | --- |
| HSR | `806071233` | `hsr:1506` を銀狼Lv.999として分離し、アイコンと虚数・歓楽を表示した。 |
| 原神 | `618285856` | ベネットを `genshin:10000032` として名称・画像・命ノ星座C6を表示した。 |
| ZZZ | `1300622089` | 星見雅を `zzz:1091` として名称・画像・心象映画M2を表示し、M2の会心率目標補正をID主キーで適用した。 |

原神シロネンは `genshin:10000103`、ZZZ浮波柚葉は `zzz:1411` を正しい主キーとして凸カタログへ登録した。近接する別ID（原神イアンサ `10000110` など）には、名前が似ていても凸効果・ガイドを推測適用しない。
