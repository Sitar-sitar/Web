# 推奨ステータス定義の設計メモ

本ツールの基礎優先度は、役割別に会心アタッカーでは会心率・会心ダメージ、持続ダメージアタッカーでは速度・攻撃力%、撃破キャラクターでは撃破特効・速度、調和サポーターでは速度・耐久、デバフサポーターでは速度・効果命中、ヒーラーでは効果抵抗・速度を重視する方針で設計した。

この方針は、ゲームエイトの「遺物厳選はいつからやるべき？・おすすめ効果」（2026年8月18日に確認）にある役割別の遺物ステータス選定を基礎とする。個別キャラクターの推奨値は、実装時点の用途を想定した初期値であり、編成・光円錐・凸状況に応じて今後更新する余地を残している。
