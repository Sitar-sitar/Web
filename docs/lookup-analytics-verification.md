# 照会分析ダッシュボード検証記録

最終確認日: **2026-08-25 JST**

本機能は、成功した公開UID照会を匿名で集計し、管理者のみが利用状況を確認するためのものです。**UID、アカウント情報、IPアドレス、キャラクター情報は保存しません**。保存対象はゲーム種別、キャッシュ利用有無、記録日時のみです。

| 確認項目 | 確認方法 | 結果 |
| --- | --- | --- |
| 匿名保存モデル | `drizzle/schema.ts`・マイグレーション確認 | `game`、`cacheHit`、`createdAt` のみを持つ `lookup_analytics_events` を追加。UIDや利用者識別子は列として定義していない。 |
| 成功照会の計測 | `server/feedback.test.ts` | 成功した照会について、ゲーム種別とキャッシュ判定を分析イベントへ記録することを確認。 |
| 管理者権限 | `server/feedback.test.ts`・`FeedbackAdmin.test.tsx` | 非管理者の集計APIアクセスを拒否し、画面上でもダッシュボードを表示しないことを確認。 |
| ダッシュボードUI | `FeedbackAdmin.test.tsx` | 合計照会数、キャッシュ利用数、キャッシュ利用率、HSR・GI・ZZZ別内訳を表示することを確認。 |
| 実集計 | 管理者ブラウザ・DB集計照合 | ZZZの明示照会で外部取得1件・キャッシュ利用1件を記録し、管理画面に合計2件・利用率50.0%・ZZZ内訳として反映されることを確認。 |
