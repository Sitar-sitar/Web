# 全キャラクター向け推奨編成カタログ設計

## 対象範囲

既存の `CHARACTER_GUIDE_CATALOG` を唯一の対象一覧として使用する。2026-08-18取得の公開メタデータでは、対象は崩壊：スターレイル81名、原神109名、ゼンレスゾーンゼロ58名、合計248名である。既存の6キャラクターは個別に精査済みの編成を維持し、残る242名はゲーム内の役割・戦闘方式・元素または属性の相性を用いて、キャラクター名を含む最大3案の個別エントリを生成する。

| データ項目 | 方針 | 更新単位 |
| --- | --- | --- |
| 個別性 | 選択中キャラクターを必ず編成に含め、主力・副火力・支援・耐久の役割を明示する | キャラクター |
| 編成案 | 相性重視、代替・入手しやすい案、汎用案の最大3案 | キャラクター／ゲームバージョン |
| 目標補正 | 公開プロフィールで比較できる戦闘外の数値だけを保持する | 編成案 |
| 主根拠 | 公式実装情報と更新日付きの総合・個別編成ガイド | ゲームバージョン |
| SNS根拠 | 公開X、HoYoLAB、Reddit等を補助根拠として記録し、主根拠との照合状態を表示する | 編成案 |

## SNSメタデータ

各編成案へ `communitySources` を必須で保持する。各要素は表示用ラベル、公開URL、確認日、採用理由、照合状態を持つ。SNSは**単独で数値目標や固定メンバーを決定しない**。更新日付き主ガイドと整合する場合は「主根拠と照合済み」、動的読み込みなどで本文が検証できない場合は「追加確認待ち」と表示する。

## 生成と手動精査の併用

カタログは、個別精査済みの明示エントリを優先し、未登録キャラクターだけにゲーム別の役割テンプレートから個別エントリを補う。これにより、バージョン更新時は主根拠・SNS候補・共通テンプレートをゲーム単位で更新し、例外や高優先度キャラクターだけを明示エントリとして差し替えられる。既存の最大3案制限、Plan選択時の目標補正、3言語テキスト、未達提案の再計算はそのまま維持する。
