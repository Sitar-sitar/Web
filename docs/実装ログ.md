**残課題・既知の問題**

- CI-03（GitHub Actions の full commit SHA pin）は未実施。P3 のため Dependabot の actions 更新運用で代替する。
- 設計書 §2.3 の制約どおり、GitHub Pages が返す実レスポンスヘッダー（CSP 等）は未確認。今回は HTML 側の meta CSP のみで対応した。
- 詳細モーダルの見た目が、デスクトップ時に画面右端へ密着する形へ変わった（従来は 16px 内側に浮いていた）。Radix Dialog の Content を配置要素にしたことによる意図的な変更。
- `rubberData.ts` の `playStyles` / `getRecommendedRubbers` は現行画面から未使用のまま残置（データモジュールの API として保持）。

**次フェーズへの申し送り**

- 依存更新は Dependabot（weekly / minor・patch はまとめ）で届く。RubberDB 側は `target-branch: RubberDB` の設定で PR が来る。
